# aidd

> The evals are the company. The code is a candidate.

Parent. Public latest. This *is* v1. Evals live here — that is the island.

Evolution is `(1+2)` plus an archive, tracked in [`aidd-evolution`](https://github.com/eidos-agi/aidd-evolution).

```
aidd                 parent / v1 / evals
aidd-v2              challenger — reimagination
aidd-v2-minimal      challenger — smallest that still holds the jobs
aidd-evolution       archive of elites
```

A clone of this repo is not a child. Two challengers must disagree. A niche win is not automatically a copy-back onto this tree.

Do not bash here. It will be overwritten if a challenger beats public and a human copies it.

## Doctrine

1. This repo is the latest public occupant. Not a workspace.
2. Challengers are concurrent theses, not serial version numbers.
3. Promote by copying a winner onto this repo. Tag the outgoing fossil.
4. The archive can keep a niche elite that is not public.
5. Tests that can be rewritten to match the code are not tests.
6. Humans own product, risk, promotion, and the oracle.

See [aidd-evolution/model.md](https://github.com/eidos-agi/aidd-evolution/blob/main/model.md), [doctrine/principles.md](doctrine/principles.md), [doctrine/field.md](doctrine/field.md).
