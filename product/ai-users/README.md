# ai-users

Personas as executable users. Not slides. Not marketing copy.

Each persona names:

- a job
- a failure mode
- an acceptance line a rebuild must still pass

A candidate that cannot complete the job, or that completes it by violating a failure mode, does not promote.

Keep personas small. One job each. When a new failure is discovered in production or in replay, add it here before the next generation.

See `templates/persona.yaml`.
