# Org layout

`(1+2)` plus archive.

```
github.com/eidos-agi/
  aidd/                 # parent. public latest. evals. this is v1.
  aidd-v2/              # challenger. reimagination.
  aidd-v2-minimal/      # challenger. smallest that still holds the jobs.
  aidd-evolution/       # archive of elites. survives copy-back.
```

Do not clone `aidd` into `aidd-v1`. Tag `aidd` instead.

Do not open `aidd-v3` because `aidd-v2` exists. A third child is only a third *different* thesis.

Evals live in `aidd`. Challengers copy them forward. They may not weaken them.

Public copy-back: tag outgoing `aidd`, copy the winning challenger onto `aidd`. A niche elite can sit in `aidd-evolution` without becoming public.
