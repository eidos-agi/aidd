# Regular width

iPad is a regular-width instrument that also becomes compact when the user splits the screen.

The home layout in wR is sidebar and detail, or an equivalent two-pane pattern, unless the product is a declared utility. A single-column iPhone layout scaled up is a fail. That miss has a name: phone-on-tablet.

Split View is not an edge case. 1/3, 1/2, and 2/3 must keep the current job usable. When the column goes compact, the iPhone plugin's compact rules apply to that column — and this plugin still owns the reflow.

Stage Manager and multiple windows are real. Two windows of the same document must not corrupt state.

Pointer and hardware keyboard are first-class. Hover may enhance. It may not be the only affordance. Touch targets stay 44pt. Core jobs are completable from a keyboard.

Popovers inspect. Full-screen sheets are for tasks. Using compact iPhone sheets for every iPad inspector is a fail.

A large empty state needs meaning, not a 44pt button in a desert.
