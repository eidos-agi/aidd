# Compact

iPhone is a compact-width instrument held in one hand.

Primary actions live where a thumb lands. Chrome is a tab bar or a compact navigation stack. Sheets, not split views. One window.

A sidebar, an inspector column, or pointer-only targets are iPad thinking. Fail them here.

Safe area is load-bearing: Dynamic Island / notch, status bar, home indicator. Content under any of them is a mechanical miss.

Portrait is the default job. Landscape is a required state, not the home. Compact landscape (wC hC) must not clip the primary action or lose the form.

System edge-swipe back is a contract. A custom gesture that eats it is a fail unless the screen is a declared immersive exception.

Phone interruptions are normal: banner, Control Center, incoming call, Face ID sheet. Form data survives them.
