# Constrained fix

Allowed without a contract change:

- Reorder existing elements
- Change use of existing tokens
- Substitute an existing component
- Add an existing state primitive
- Improve labels under the copy guide

Requires a design-contract update:

- New color role
- New typography scale
- New component primitive
- New navigation interaction model
- New animation language

The smallest design-system-preserving patch wins. Inventing a new visual language to satisfy the critic is a fail.
