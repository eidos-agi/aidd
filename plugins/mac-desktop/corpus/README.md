# Corpus

An AI cannot infer this product's taste from HIG alone.

Keep:

- **approved/** — screens you would still ship. Task, state, why the composition works, screenshot, trees.
- **anti-patterns/** — rejected variants labeled with the exact miss (competing CTAs, card nesting, Oops, lost input).
- **pairs/** — winner/loser with why. Comparisons teach faster than absolute scores.

Every accepted UI becomes a positive. Every rejected PR becomes a negative. That is calibration, not a mood board.

Held-out copies live in `plugin-evals/mac-desktop/`. The candidate does not edit those.
