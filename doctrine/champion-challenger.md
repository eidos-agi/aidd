# Generations compete. The winner is copied.

Do not treat `product` as a champion. Treat it as the last published snapshot.

```
product-v1 ──▶ product-v2 ──▶ product-v3     work
                   │
                   └── copy winner ──▶ product     public
```

Each `vN` must beat what is currently in `product` (the last winner). A higher number is not a successor. `v2` can lose. If it loses, `product` still shows `v1`.

You can open two theses at once (`product-v2`, `product-v2-smaller`) if search needs it. Only a copy-back makes it public.

Do not bash in `product`. Do not clone the last winner’s internals as a prison. Copy the evals forward. Rebuild the implementation.

A smaller generation that holds every remaining job and every hard gate is a promotion. A candidate that edits its own grader is not a candidate.
