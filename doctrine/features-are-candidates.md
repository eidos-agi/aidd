# Features are candidates

The evals are the company. The code is a candidate. The feature is a candidate too.

Aidd without this stool is an accumulation engine. Agents add. Tests ask whether the addition still works. Nothing asks whether it should still exist.

```
                     ┌── candidate A (add)     ──┐
product (champion) ──┼── candidate B (same)    ──┼── evaluation ──> next champion
                     └── candidate C (smaller) ──┘
```

A smaller candidate that holds every remaining user job and every hard gate is a promotion. A cleaner-looking candidate is not. A cheaper candidate that drops a job is not.

Ties on jobs with higher burden stay with the smaller one only when the burden drop is named and the jobs still pass. Ties on jobs with equal burden stay with the champion.

Deletion is search. Deprecation theatre is not.
