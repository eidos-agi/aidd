# Principles

`product` is the latest copy of the winner. It is not a workspace. It is not an oracle.

Work happens in `product-v1`, `product-v2`, `product-v3`. Promote by copying the winning generation onto `product`.

Code is a byproduct of intent, oracles, and fitness.

A rebuild is a new generation repo, not a confession.

Promotion is evidence-gated. A new generation must beat the current latest on the same tests, the same corpus, and the same scorer. Ties stay with what is already in `product`.

Evals travel with the generation. They accumulate. They copy forward. They are not owned by the public repo. The public repo only has them because they arrived with the winner.

Humans own product, risk, promotion, and the oracle. AI owns generation, search, and mechanical execution.

Tests that can be rewritten to match the code are not tests.

The public sees the major upgrade. The org keeps the generations.

The evals are the company. The code is a candidate. The feature is a candidate too.

Verifiability sets the automation ceiling. What you cannot check, a human still owns.

Do not bash in `product`.
