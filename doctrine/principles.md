# Principles

Code is a byproduct of intent, oracles, and fitness.

A rebuild is a new generation, not a confession.

Promotion is evidence-gated. A new generation must beat the current champion on the same tests, the same corpus, and the same scorer. Ties stay with the champion.

Tests, oracles, contracts, and fitness live longer than any implementation. Code may be discarded. Evals may not.

Humans own product, risk, promotion, and the oracle. AI owns generation, search, and mechanical execution.

Tests that can be rewritten to match the code are not tests. They are documentation of the current candidate.

The public sees the major upgrade. The org sees the competition that produced it.

The evals are the company. The code is a candidate.
