# /aidd-prune

Reduce complexity. Kill unearned surface. Features are candidates.

1. Read `product/simplicity-standards/README.md` and `doctrine/features-are-candidates.md`.
2. Load the inventory. Map every feature to an `ai-users` job. Undeclared surface is a fail.
3. Do not start a rebuild. Prune in place first. Rebuild only if `doctrine/rebuild-triggers.md` fires.
4. Propose deletions with evidence. Telemetry, superseded-by, incident cost, or owner declaration. Taste is not evidence.
5. Run every remaining job and every other-leg hard gate. A dropped job is a reject.
6. Additions pay the tax: job, burden, kill condition. No kill condition, no merge.
7. Public contracts need a sunset and a human signature.
8. Do not edit `simplicity-standards/` or the inventory to hide surface in the same run that authors the change.

The Pruner is not the Builder. A smaller candidate that holds the jobs is a promotion.
