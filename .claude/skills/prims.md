# /prims

A **Prim** is the file that stores the information. A **Prim Tool** is how you interact with it.

Pronounce /prɪm/. Say “send me the prim.” The spreadsheet is a view.

Home: https://github.com/eidos-agi/prim — read `WHAT-IS-PRIM.md` and `SPEC.md` before inventing a pack. Live types/tools: `registry/registry.json`. FAMILY.md is a sketch.

OKF is one grammar. Prim is not OKF. Not every Prim is an OKF pack.

Closed primitives: file, face, authority, constraint, log, validator, ui, compose, trust. Profiles add domains. They do not add a tenth primitive.

Prim Tools are **surface** (human) or **connector** (system). They cite the file. Do not mint `prim.surface` or `prim.connector`. If it is not surface or connector, it is a script. `ui` opens. A tool operates. Compose cites; it does not copy claims.

Repos: `prim` (category), `prim.<profile>` (domain), `prim-web` (views, never the store), `prim-mac` (Prim.app).

AIDD evals are the method’s island. A Prim is a knowledge file. Do not call doctrine a prim unless it is packed as one.

Not Second Life prims. Not chat memory. A Prim is a file that outlives the session.
