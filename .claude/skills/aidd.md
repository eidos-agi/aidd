# /aidd

The method.

Read `README.md` and `doctrine/principles.md` first. Then:

1. Name the public repo. It is `product`. For this forge: `eidos-agi/aidd`. It is the latest copy of the winner. Not a workspace.
2. Name the generation repo. It is `product-vN`. That is where you bash.
3. Copy evals forward from the current latest. If there are none, extract contracts before generating code.
4. Name the five legs. Copy templates from the current latest if they are missing.
5. Name the plugins the surface needs. Do not collapse them.
6. Do not start a rebuild because the code is ugly. Check `doctrine/rebuild-triggers.md`. A trigger opens the next `vN`.
7. Read `doctrine/field.md` once. Error analysis first. Held-out is locked. Teeth or the suite is theater.

Do not edit held-out evals in the same run that authors a candidate. Do not bash in `product`.
