# /aidd

The method.

Read `README.md` and `doctrine/principles.md` first. Then:

1. Name the champion.
2. Name the frozen evaluator. If there is none, stop and extract contracts before generating code.
3. Name the three legs. If `ai-users/`, `frontend-testing-standards/`, or `data-testing-standards/` are missing, copy templates from this forge.
4. Do not start a rebuild because the code is ugly. Check `doctrine/rebuild-triggers.md`.
5. Speak in generations, not versions. `next` until it earns a release.

Do not edit `product-evals/` in the same run that authors a candidate.
